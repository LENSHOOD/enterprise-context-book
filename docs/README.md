# 项目文档

本目录保存书稿之外的项目治理和发布材料：

- `BOOK_CHARTER.md`：写作定位、范围和完成标准；
- `CASE_SPEC.md`：Northstar 与 Linux 案例的目标和实际交付边界；
- `OUTLINE.md`：18 章、番外和附录的结构；
- `LINUX_CASE_DECISION.md`：Linux 案例选型记录；
- `RELEASE_AUDIT.md`：`rc.3` 历史发布审计；当前 `rc.9` 候选以最新复核和 CI 记录为准。

历史同行评审及其处置记录保留在根目录的 `reviews/`，避免改变审阅链路。书稿位于 `book/`，可运行案例位于 `examples/`。
