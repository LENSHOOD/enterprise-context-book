# 详细目录 v1.0.0-rc.13

> 文档类别：书稿结构与章节范围。

本目录反映当前 18 章、番外与附录 A—G 的实际结构；`reviews/run_manifest.json` 是历史审计记录，当前版本状态以仓库提交与 GitHub Actions 为准。

## 第一部 为什么需要企业上下文

### 第 1 章 智能体为什么不懂企业

用退款处置和销售分析引出企业上下文，以资源、平台和具体任务的关系建立整体认识，并介绍从战略到运行的企业上下文内容体系。

### 第 2 章 从知识管理到企业上下文

回顾文档管理、数据库与搜索、专家系统、EA、语义建模、向量、RAG 和 Agent 的发展，将各自贡献映射到第一章总图，不把演进写成线性替代。

### 第 3 章 企业上下文怎样组织起来

同时展开资源与平台：资源按企业内容体系、业务对象与关系、描述材料组织，用销售关系图及知识、观测、记忆对照表说明内部结构；平台负责资源维护、语义与治理、上下文构造。再说明来源与任务材料如何管理和使用，并给出第二部分技术导航。

## 第二部 知识如何进入智能体

### 第 4 章 RAG：让模型访问外部证据

讲解摄入、解析、分块、Embedding、检索、重排、引用及基础 RAG 的能力边界。

### 第 5 章 从单路搜索到混合检索

比较 BM25、Dense Retrieval、Late Interaction、结构化过滤、RRF、Reranker、多跳和查询规划。

### 第 6 章 从片段到层级知识

讨论父子块、RAPTOR、PageIndex、全局与局部查询，以及层级摘要如何恢复整体理解；说明知识视图与企业架构 viewpoint/view 的关系及边界。

### 第 7 章 Wiki：把反复查资料的工作提前做好

介绍 Raw Sources、Schema、Ingest、Query、Lint、互链、增量更新、人工编辑和缓存失效。

### 第 8 章 知识建模、本体与图谱：让系统听懂企业在说什么

区分 taxonomy、Schema、本体与知识图谱，建立概念、逻辑和物理三层模型；引入企业架构元模型、DDD 限界上下文/统一语言和业务流程层级；介绍从能力问题到实体、关系、约束、源映射和治理的完整流程；以 Palantir Ontology 为运营本体参照，说明对象、链接、函数、Action、权限与应用闭环的关系；并讨论 RDF/OWL/SHACL、实体消歧、GraphRAG、代码图与时间图谱。

### 第 9 章 记忆：让智能体延续经验

区分会话、用户、任务、Agent 和组织记忆，讨论提取、合并、按类型压缩、环境核验、遗忘/回滚、时序、隐私和投毒。

## 第三部 企业上下文平台

### 第 10 章 把零散知识能力装成一个平台

给出来源、解析、知识编译、多模型索引、查询规划、混合召回、证据解析、上下文打包、Agent Skills、MCP/A2A 边界和反馈治理的总体架构。

### 第 11 章 同一份知识，怎样避免认错版本和时间

讲连接器、统一 ID、provenance、快照、有效时间、冲突、删除传播和派生知识 lineage。

### 第 12 章 Agent 能看什么、记什么、改什么

讲召回前鉴权、多租户、权限域摘要、提示注入、记忆投毒、MCP、工具授权、审批、审计和回滚。

### 第 13 章 怎么知道知识系统真的有用

分层评测解析、召回充分性、图、Wiki、记忆、生成、Agent 和安全；介绍端到端 RAG、Golden Evidence、消融实验、SLO、成本和持续反馈。

## 第四部 从零构建一个企业上下文系统

### 第 14 章 成品导览与构建路线

先展示 Northstar 的战略分析、影响分析与退款处置成品，说明企业上下文内容体系与当前任务条件，区分目标企业、教学 fixture 和生产替换路线，再给出 C0-C7 的构建顺序和验收点。

### 第 15 章 从来源到可信检索

从企业检索必须守住的身份、版本、权限、时间和证据约束出发，解释来源类型、对象编译、ACL-first、多通道规划、RRF、双时间与安全降级，再映射到 C0-C2 的可运行实现。

### 第 16 章 让系统按企业的含义连接知识

从战略分析、变更影响和执行处置三个能力问题出发，完整展开对象身份、关系契约、时间边、源映射、模型编译和连通实例验证；再解释能力问题约束下、保留语义方向的正反向图导航，以及 Wiki、任务记忆和企业架构各自回答什么问题，映射到 C3-C4 与 C7 实现。

### 第 17 章 让 Agent 安全地把事情做完

设计战略分析包、变更影响包和执行行动包，说明它们如何共享身份、版本、证据和权限底座；再讲组装流程、动态工具可见性和确定性状态机，解释预览、确认、并发、幂等、部分成功、独立验证与审计，映射到 C5-C7 实现。

## 第五部 真实世界压力测试

### 第 18 章 动手构建一个 Linux eBPF 知识库

固定上游版本，以 eBPF 建立 syntax-only 源码结构、符号候选关系、层级 Wiki、BM25 查询和可验证源码引用；明确 Tree-sitter/SCIP/BTF/向量检索属于后续精度路线，分析宏、条件编译、大仓增量和扩展到全内核的挑战。
