## 关于本书

企业智能体能否完成研发、IT、运营和销售工作，取决于它是否获得了正确的企业上下文。这里的上下文不只是向量库中的文档，还包括规范知识、派生解释、关系、记忆、实时状态、权限、工具和当前任务。

本书面向 AI 平台负责人、架构师和高级工程师。正文保持厂商中立，配套案例提供无商业 API 也能运行的本地路径。所有技术结论尽量回到论文、规范、官方文档或版本化源码。
