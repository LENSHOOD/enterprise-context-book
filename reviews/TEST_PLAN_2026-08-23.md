# v1.0 发布测试计划

## 文稿与事实

- 为每个外部事实生成 `claim_id`、章节定位、来源、支持状态和审阅人。
- 校验完整 Bibliography 与正文链接一一对应。
- 自动禁止“当前最新”“完整实现”“全部通过”等无时间或证据限定的绝对表述。
- 统一统计汉字、中文词、英文词、代码和引用的口径。

## 文档命令

- 抽取所有 `bash` 代码块，在隔离临时目录执行。
- 对破坏性、需要网络或大规模数据的命令标记执行策略。
- fixture 路径必须在 CI 中完整执行；Linux 全仓路径至少验证 CLI 参数和小仓 fixture。

## Northstar

- 数据规格数量门：逻辑仓、ADR、Runbook、Schema、配置、工单和 Golden Questions。
- 六类强制任务逐题验证必要证据、禁止证据、角色、租户、时间与快照。
- 提示注入不能改变检索策略、工具可见性或记忆写入。
- 审批令牌绑定主体、任务、工具、参数散列和 TTL；过期及参数变化必须失败。
- 写工具重复调用满足幂等；执行后必须读取真实状态验证。
- 向量、图、重排故障时显式降级；权限服务故障时关闭访问。
- 删除来源后块、向量、图、Wiki、缓存和记忆候选均按策略撤销。

## Linux

- fixture 验证 BM25、向量、图通道及融合消融。
- 语法候选、名称解析、编译关系和运行观察使用不同边类型。
- 宏、函数指针、同名静态函数、Kconfig 和架构条件进入误差分桶。
- 全仓摄取支持中断恢复、磁盘不足、损坏数据库和增量更新。
- 查询验证空字符串、特殊字符、中文、精确符号、子系统过滤和无结果。

## 站点与发布

- 6 个 Mermaid 图必须生成可访问 SVG，而非代码块。
- 检查桌面、375px 移动端、键盘导航、对比度、图片替代文本和搜索。
- 对每页执行内部链接、外链、标题层级和重复 ID 检查。
- 验证 GitHub Pages 实际 URL、404 页面、base path、v1.0 tag 和引用版本。
- LICENSE 与 LICENSE-CODE 使用官方完整文本，文件范围清楚且与页面一致。
