# Northstar 工作台与交互教程：实现检查

日期：2026-10-07。基线：main `f163873`；工作分支：`codex/northstar-interactive-tutorial`。

## 本轮完成的内容

第14章先解释资源、平台、任务的实际模块与技术，再说明任务流转、资源更新和启动方式。第15—17章分别嵌入三个实验，将设计解释、真实源码、可调整输入、结果和失败边界放在阅读位置。工作台与章节实验复用同一组件和同一 Python 核心。

新增的应用层保存独立实验空间、任务条件、上下文快照、工作笔记、批准和回执。SQLite 将一次请求中的任务与模拟业务状态一起提交。政策更新只修改当前空间副本，重新编译后标记旧任务需要重新取证，历史快照不覆盖。已有动作预览的事故任务不能继续使用旧批准。

HTTP 接口只监听本机，检查 Host、Origin 和结构化请求头，没有任意 shell 入口。页面允许切换教学角色；服务端仍检查各角色的资源和任务边界，但这不是生产身份认证。

## 审阅中修正的问题

- 容器与宿主机目录深度不同，根目录不再依赖固定的高层索引；通过实际容器运行验证。
- 当前任务状态与上下文快照中的旧状态分开显示；快照不会因后续动作而被悄悄改写。
- 每次上下文构造产生独立追踪标识；源代码版本绑定进程已载入版本，避免编辑磁盘文件后伪装成新版执行。
- 无扩展名路径补齐`.html`、目录补齐`index.html`后，再次解析并检查路径范围。新增回归先复现站外符号链接可读，再确认修复后的403拒绝；17项工作台测试重新通过。
- 静态预览进程在重建后需要重启，否则旧文件清单导致新资源404。本次重启后已确认样例按钮正常。

## 明确保留的教学边界

- 本例执行真实Python代码，但业务数据、身份和时钟为模拟，不接真实退款或经营系统，也不包含自动规划的模型Agent。
- 公共GitHub Pages仅提供书稿、源码与构建时示例。实际执行使用本机Python服务；公共页面不探测访客的本地网络。
- SQLite保存小空间的完整状态；事务不覆盖外部业务工具，不代表分布式工作流实现。
- 政策更新保守标记全部旧任务，不声称已做精确增量失效。源代码版本变化后需要新建空间；本版没有旧空间选择器。
- 章节中的源码直接从函数和输入文件提取；页面不提供在线代码编辑器。修改实现仍在本地源文件进行，随后重建并重启。
- W2和Linux仍是独立练习，尚未接入工作台。原有VitePress大分块提示未在本轮处理。
